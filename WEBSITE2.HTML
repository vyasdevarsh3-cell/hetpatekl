About Algorithms

1. SCAN Algorithm

The SCAN algorithm moves the disk head in one direction, servicing all requests along the way. It reaches the end of the disk and then reverses direction.

2. C-SCAN Algorithm

The C-SCAN algorithm services requests in one direction. After reaching the disk boundary, the head returns to the opposite boundary without servicing requests during the return trip. It then continues servicing requests.
